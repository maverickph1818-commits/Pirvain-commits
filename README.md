## 💎 Featured Project

### 🔹 [Semantic Cache Router](https://github.com/maverickph1818-commits/semantic-cache-router)

An AI-powered project exploring semantic caching to reduce repeated LLM calls and cost-aware routing to help manage model usage.

**What it explores:**
- 🧠 Semantic similarity-based response caching
- ⚡ Reusing cached responses for similar requests
- 📊 Cache-hit, cache-miss, and response-time analytics
- 💰 Estimated API cost tracking
- 🖥️ Interactive Streamlit dashboard

**Technologies:** Python · FastAPI · Redis · Streamlit · Sentence Transformers · Groq API
