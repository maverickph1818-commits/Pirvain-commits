## 💎 Featured Project

### 🔹 [Semantic Cache Router](https://github.com/maverickph1818-commits/semantic-cache-router)

An AI-powered project exploring semantic caching to reduce repeated LLM calls and help manage model usage.

**Project highlights**
- 🧠 Semantic similarity-based response caching
- ⚡ Cache-hit and cache-miss tracking
- 📊 Response-time analytics
- 💰 Estimated cost tracking
- 🖥️ Interactive Streamlit dashboard

**Stack:** Python · FastAPI · Redis · Streamlit · Sentence Transformers · Groq API
