## 💡 Featured Project

### [Semantic Cache Router](https://github.com/maverickph1818-commits/semantic-cache-router)

An AI-powered application exploring how semantic caching can reduce repeated LLM calls and how cost-aware routing can help manage model usage.

**Highlights**
- Semantic similarity-based response caching
- LLM API integration
- Cache-hit and cache-miss tracking
- Response-time analytics
- Estimated cost tracking
- Interactive Streamlit dashboard

**Built with:** Python, FastAPI, Redis, Streamlit, Sentence Transformers, and Groq API.
